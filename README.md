# 🎁 Event Landing Page & Reward System

A professional, responsive event landing page and registration form built using **HTML5** and **CSS3**. This project was designed to showcase event details, feature presenters/speakers using CSS Grid, and collect user registration data along with Dojo points.

---

## ✨ Features

* **Modern Hero Section:** Eye-catching headline, event details, and custom image layout.
* **Responsive Grid Presenters Section:** A clean 3-column CSS Grid layout showcasing event presenters and coaches with circular avatars.
* **Dedicated Registration Page (`reg.html`):** A clean user form to collect Full Name, Email ID, Class/Batch, and Dojo Points.
* **Pure HTML & CSS Architecture:** Built from scratch using CSS Variables (`:root`), Flexbox, CSS Grid, Box Model, and smooth hover transitions (no JavaScript required).
* **Fully Responsive:** Mobile-friendly design powered by CSS Media Queries.
